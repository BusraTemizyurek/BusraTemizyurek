## 👩🏻‍💻 About Me:

🚀 I'm a full-stack software developer currently at **Veritree**, building production web applications and cloud-integrated services using TypeScript, React, Vue.js, Node.js/Fastify, PostgreSQL, and REST APIs. I design scalable backend architectures, geospatial workflows, and data-driven features — and I obsess over clean, maintainable code.

🔧 I enjoy building side projects like an AI-powered math tutor app, Thirsty Plant (IoT moisture monitor with real-time dashboard), Moto-Perf (motorcycle performance tracker), an AI product-support chatbot, and more.

🌍 Active in open source — publishing npm packages (data structures, utilities) and sharing code to give back to the community.

💬 I'm passionate about writing clean, maintainable code and building applications that solve real problems. I enjoy collaborating across cross-functional teams and leveraging AI tooling to ship higher-quality products faster.

⚡ Fun fact: I've been skating since I was 7 and love activities like sailing, cycling, and snowboarding.
